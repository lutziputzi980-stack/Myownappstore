# Spielplatz — dein eigener Spiele-Store

Eine responsive, deutschsprachige Store-Webseite für Browsergames. Die Seite läuft als statische Website und benötigt zum Ausprobieren keine Installation und kein Backend.

## Funktionen

- Spielekatalog mit Suche, Kategorien und Sortierung
- Vier integrierte Mini-Browsergames zum direkten Ausprobieren
- Spiele merken und lokal im Browser speichern
- Eigene einzelne HTML-Spiele über **„Spiel hinzufügen“** in die lokale Sammlung aufnehmen
- Spiele starten in einem sandboxed iframe
- Für Smartphone und Desktop optimiert

## Lokal starten

`index.html` kann direkt im Browser geöffnet oder über einen statischen Webserver bereitgestellt werden.

## Im Internet veröffentlichen

Die Dateien können auf GitHub Pages oder einem anderen statischen Webhost veröffentlicht werden. Bei GitHub Pages muss die Quelle auf den Branch `main` und den Ordner `/ (root)` zeigen.

**Hinweis:** Hochgeladene Spiele und Merkliste werden nur im lokalen Browser gespeichert. Besucher eines veröffentlichten Stores sehen die vier integrierten Demo-Spiele, aber nicht die lokalen Uploads anderer Besucher. Für einen gemeinsamen öffentlichen Katalog mit Konten und Uploads ist zusätzlich ein Backend bzw. eine Datenbank erforderlich.
